# Between Trainings and Progress

> We have data and process.

Between Trainings and Progress (BTP) is a sports analytics project focused on transforming training data into meaningful performance insights.

## Status

🚧 Early development

## Vision

Training generates enormous amounts of data.

BTP aims to help athletes understand what happened, why it happened, and how it relates to their long-term progress.

## Tech Stack

- Next.js
- TypeScript
- PostgreSQL
- Strava API
- Python
- Google Colab
